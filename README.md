# Colorfly Studio 🎨

Generador de paletas de colores aleatorias para crear combinaciones de colores de forma sencilla.

## ¿Qué hace?

La aplicación permite:

* Generar paletas de 6, 8 o 9 colores.
* Elegir entre formatos HEX y HSL.
* Bloquear colores para mantenerlos al generar una nueva paleta.
* Copiar el código de un color haciendo clic sobre él.
* Guardar una paleta en el navegador.
* Recuperar la paleta guardada después de recargar la página.

## ¿Cómo usarlo?

1. Seleccionar la cantidad de colores.
2. Elegir el formato HEX o HSL.
3. Presionar **Generar paleta**.
4. Hacer clic en un color para copiar su código.
5. Usar el botón de bloqueo para conservar un color.
6. Presionar **Guardar paleta** para guardarla.

## Decisiones técnicas

El proyecto fue realizado utilizando:

* HTML para la estructura.
* CSS para los estilos y diseño responsive.
* JavaScript para la generación de colores y la interacción.
* "localStorage" para guardar las paletas en el navegador.
* Git y GitHub para el control de versiones y publicación.



## Ejecución

El proyecto está publicado en GitHub Pages, por lo que puede utilizarse directamente desde el navegador sin necesidad de instalar dependencias.

Para utilizarlo:

* Ingresar al enlace de la aplicación.
* Seleccionar la cantidad de colores.
* Elegir el formato HEX o HSL.
* Presionar Generar paleta.
